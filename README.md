# Discover Kashmir: A Next.js Blog
This is a blog application built with Next.js to showcase the breathtaking beauty of Kashmir. It aims to be a comprehensive resource for travelers and anyone interested in exploring the region's rich history, culture, and stunning landscapes.

## Tech Stack
### Frontend : Next.js (with server side rendering support)
### Backend : MERN Stack (MongoDB, Express, Node.js)
## Features
Content Management System : Easily add, edit, and publish blog posts about Kashmir's hidden gems, must-see attractions, and local experiences. <br />
SEO Optimization : Optimized for search engines to ensure maximum visibility for potential visitors to Kashmir. <br />
Image Support : Showcase the captivating beauty of Kashmir with high-quality images. <br />
Dynamic Content : Content updates seamlessly without requiring full page reloads. <br />
Authentication : Signup , login and logout features. <br />
Switching between dark and light mode. <br />

## Getting Started
### Prerequisites:

Node.js and npm (or yarn) installed on your system.
1. Clone the Repository <br />
git clone https://github.com/syed-shaida-hussain/discover-kashmir

2. Install Dependencies <br >

cd discover-kashmir <br />
  npm install

3. Start the Development Server <br />

  npm run dev <br />

This will start the development server at http://localhost:3000 by default. You can now access the application in your web browser. <br />
